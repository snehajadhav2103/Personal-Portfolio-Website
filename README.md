# Personal Portfolio Website

A responsive personal portfolio template built with HTML, CSS, and JavaScript.

## Sections
- Introduction / hero
- About
- Skills
- Project cards
- Contact details

## View the website
Open `index.html` in a web browser. No build tools or installation are required.

## Personalize before publishing
1. Replace every `Your Name` placeholder with your name.
2. Replace `your.email@example.com` with the email address you want to publish.
3. Update the About section and skills to match your real background.
4. Replace the generic GitHub profile link with your profile URL.
5. Add project repository links after uploading your projects.

## Technologies
HTML5, CSS3, JavaScript.
